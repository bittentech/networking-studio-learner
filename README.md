# Bitten Tech Networking Studio

A free, interactive networking lab for beginners learning cybersecurity. Follow the Bitten Tech video series and try the diagrams, exercises and packet captures yourself.

**[Download the Learner Edition ZIP](../../releases)** · **[Watch the series from Part 1](https://www.youtube.com/watch?v=4hLax8DmQHY)**

1. Under **Assets** on the latest release, download the `Networking-Studio-Learner` ZIP.
2. Extract the entire ZIP and open `index.html` in your desktop browser.
3. Choose a part, try the exercises and use the included captures when a lesson calls for Wireshark.

The Studio lessons work offline. YouTube and external references need an internet connection. This repository distributes the free Learner Edition and its release notes. Asset credits are included in the ZIP.
